## Overview

Brigid is a Haskell library for constructing and rendering HTML, and HXML,
with the structure of the document checked by the type system. Its own
description is “type-safe and (mostly) spec-compliant HTML”.

This site is its first portfolio-scale user: every page here is generated by
a small Haskell program that builds its markup with Brigid, including this
page, whose text is written in Markdown and converted into Brigid elements.

## Technical approach

Each element states which children it may contain. Placing an element where
the library’s rules do not allow it is a *compile-time* error rather than a
problem discovered later in a browser. Building the Markdown renderer for
this page produced exactly such an error:

```text
• The Anchor (<a>) element is not a valid child for the Emphasis (<em>) element.
```

Attributes are typed in the same way, and documents are ordinary Haskell
values, so a page can be assembled from functions. A fragment of this site’s
project navigation:

```haskell
E.nav [ A.class_ "project-nav", A.aria_label "Project" ]
  [ E.a [ A.class_ "project-nav__back", A.href (routeUrl WorkIndex) ]
      [ E.span [ A.class_ "project-nav__arrow", A.aria_hidden True ] [ E.text "←" ]
      , E.text "All projects"
      ]
  ]
```

## Current capabilities

- HTML elements and attributes, with nesting checked by the types.
- HXML documents, alongside HTML.
- Rendering to `ByteString`, `Text` or `String`.
- “Safe” constructors for elements with more complex content rules, such as
  the `<meta>` element used in this site’s document head.
- Typed attributes for htmx.

## Limitations and status

Brigid is in active development, and its API is not yet stable. The
“(mostly)” is deliberate:

- The types capture many of the HTML specification’s content rules, not yet
  all of them.
- Some rules are stricter than the specification. For example, a link inside
  emphasis or inside a level-three heading is valid HTML but is rejected, so
  this site’s Markdown rejects those combinations too.
- SVG support is partial (the `svg`, `g` and `path` elements so far), and
  MathML and further “safe” element builders are listed in the project’s
  plans rather than finished.
